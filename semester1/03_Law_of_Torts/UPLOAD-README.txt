LAW OF TORTS – UPLOAD PACKAGE

This package contains 11 replacement HTML files:
- index.html
- unit-1-notes.html through unit-5-notes.html
- qa-unit-1.html through qa-unit-5.html

UPLOAD INSTRUCTIONS
1. Make a backup of your current Law of Torts folder first.
2. Upload these 11 files into the same folder that currently contains index.html.
3. Choose Replace/Overwrite when prompted for these matching filenames.
4. Keep these existing files unchanged: case-law.html, gap-report.html, problem-bank.html,
   revision.html, revision-checklist.html and README.txt.
5. Open index.html and test every Unit Notes and Exam Q&A link.

CONTENT SOURCE
The five complete study pages and five exam Q&A pages were taken from the supplied
older HTML files. The shorter files ending in -study-del were placeholders and were
not used.

IMPORTANT
The package does not replace or rewrite the existing case-law, gap-report, problem-bank,
or revision pages. Review those separately before making changes.
