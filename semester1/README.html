Offline use and static deployment

← Central dashboard

Offline use

  1. Extract the ZIP, preserving all folders.
  2. Open KSLU_Semester_1/index.html in Chrome, Edge or Firefox.
  3. Use central search to search the HTML pages indexed at build time.
  4. Open subject indexes to reach unit notes and Q&A.
  5. Use the progress checklist and print controls. Ticks are stored locally in that browser/device.

Internal links are relative. Core pages work offline; external citations require internet access.

Static deployment

  1. Upload the entire extracted folder to GitHub Pages, Netlify, Render Static Site or another static host.
  2. Set the publish/root directory to KSLU_Semester_1.
  3. Do not flatten or rename subject folders; relative links depend on the structure.
  4. After editing pages, rebuild the embedded search index and retest links.

Limitations

Not 100% complete. Family Law I has placeholders only. English applicability and exact text/translation alignment require confirmation. Other subject packages contain audit-listed verification tasks. See the consolidated gap report.

Personal study resource, not an official KSLU publication. Current syllabus, prescribed texts and bare Acts are final authority.
